# 🛒 E-Commerce Sales Analytics

A complete Data Analytics project that explores an e-commerce sales dataset using **Python, SQL, and Power BI** to uncover business insights, sales trends, customer behavior, and operational performance.

---

## 📌 Project Overview

This project analyzes **5,000 e-commerce transactions** to answer key business questions related to sales, customer satisfaction, regional performance, payment preferences, and product categories.

The objective is to transform raw sales data into meaningful insights through data cleaning, exploratory data analysis (EDA), SQL querying, and interactive Power BI dashboards.

---

## 📂 Dataset Information

- **Dataset:** E-Commerce Sales Analytics
- **Records:** 5,000
- **Columns:** 12

### Features

| Column | Description |
|----------|-------------|
| order_id | Unique order ID |
| order_date | Date of purchase |
| customer_id | Customer identifier |
| product_category | Product category |
| region | Sales region |
| quantity | Quantity sold |
| unit_price | Price per unit |
| discount | Discount applied |
| payment_method | Payment method |
| delivery_days | Delivery time |
| customer_rating | Customer satisfaction rating |
| revenue | Revenue generated |

# 📌 Key Business Insights

### 💰 Revenue

- Strong revenue generated across multiple product categories.
- Electronics contributes the highest revenue.

### 🛍 Product Categories

- Electronics is the best-performing category.
- Beauty has the lowest revenue and presents an opportunity for growth.

### 🌍 Regional Performance

- Revenue is balanced across all regions.
- West region slightly outperforms others.

### 💳 Payment Methods

- Card payments are the most frequently used.
- Wallet adoption can be improved.

### ⭐ Customer Satisfaction

- Average customer rating indicates room for improvement.

### 🚚 Delivery Performance

- Average delivery time suggests logistics optimization opportunities.
